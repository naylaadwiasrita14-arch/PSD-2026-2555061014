**PENCARIAN DATA BUKU ERDASARKAN KODE BUKU** 


Program ini dirancang untuk menyimpan dan mengelola data buku dengan menggunakan kode buku sebagai identitas utama. Melalui program ini, pengguna dapat menambahkan data buku ke dalam sistem, mencari informasi buku berdasarkan kode buku, menampilkan seluruh data yang tersimpan, serta menghapus data yang sudah tidak diperlukan. Dengan memanfaatkan kode buku sebagai acuan pencarian.





Dalam implementasinya, program akan menggunakan struktur data HashMap yang dipadukan dengan metode Separate Chaining. HashMap yang berfungsi sebagai media penyimpanan pasangan data yang terdiri dari kode buku sebagai key dan judul buku sebagai value. Sementara itu, metode ini digunakan untuk mengatasi masalah collision, yaitu kondisi ketika beberapa kode buku menghasilkan indeks penyimpanan yang sama. Untuk menangani hal tersebut, setiap bucket pada hash table dihubungkan dengan linked list, sehingga beberapa data tetap dapat disimpan pada indeks yang sama tanpa menyebabkan kehilangan data.

Pada codingan baris ke-1 yaitu class Node:, kode ini memiliki fungsi untuk membuat sebuah kelas bernama Node yang digunakan sebagai tempat penyimpanan data pada linked list. Pada codingan baris ke-2 yaitu def __init__(self, kode_buku, judul_buku):, kode ini berfungsi sebagai constructor yang akan dijalankan secara otomatis saat objek Node dibuat. Pada codingan baris ke-3 yaitu self.key = kode_buku, kode ini memiliki fungsi untuk menyimpan nilai kode buku ke dalam atribut key. Kemudian pada codingan baris ke-4 yaitu self.value = judul_buku, kode ini digunakan untuk menyimpan judul buku ke dalam atribut value. Selanjutnya pada codingan baris ke-5 yaitu self.next = None, kode ini berfungsi untuk menginisialisasi pointer next dengan nilai None, yang menandakan bahwa node tersebut belum terhubung dengan node lainnya.

Pada codingan baris ke-1 yaitu class HashMapSeparateChaining:, kode ini berfungsi untuk membuat kelas yang akan digunakan sebagai implementasi HashMap dengan metode Separate Chaining. Pada baris ke-2 yaitu def __init__(self, size=10):, kode ini digunakan sebagai constructor yang akan dijalankan saat objek dibuat. Kemudian pada baris self.SIZE = size, nilai ukuran HashMap disimpan ke dalam atribut SIZE. Selanjutnya pada baris self.table = [None] * self.SIZE, program membuat sebuah list dengan ukuran sesuai nilai SIZE dan seluruh elemennya diisi None. List ini nantinya akan digunakan sebagai hash table untuk menyimpan data buku.














Pada codingan baris def hash_function(self, key):, kode ini berfungsi untuk membuat fungsi hash yang digunakan dalam menentukan posisi penyimpanan data pada hash table. Kemudian pada baris return (key % self.SIZE + self.SIZE) % self.SIZE, program menghitung indeks berdasarkan nilai key menggunakan operasi modulo. Hasil perhitungan tersebut akan menghasilkan indeks yang berada dalam rentang ukuran hash table sehingga data dapat ditempatkan pada bucket yang sesuai.



















Pada codingan baris def insert(self, key, value):, kode ini digunakan untuk menambahkan data ke dalam HashMap. Baris index = self.hash_function(key) berfungsi untuk mencari indeks penyimpanan berdasarkan key yang diberikan, sedangkan current = self.table[index] digunakan untuk mengambil data yang berada pada indeks tersebut. Pada bagian while current is not None, program melakukan pengecekan apakah key yang dimasukkan sudah ada atau belum. Jika ditemukan key yang sama, maka nilai akan diperbarui melalui current.value = value. Namun jika key tidak ditemukan, program akan membuat node baru menggunakan new_node = Node(key, value). Setelah itu, node baru dihubungkan ke linked list yang sudah ada melalui new_node.next = self.table[index] dan ditempatkan pada awal bucket dengan self.table[index] = new_node. Dengan cara ini, collision dapat ditangani menggunakan metode Separate Chaining.

Pada codingan baris def search(self, key):, kode ini berfungsi untuk mencari data berdasarkan key yang diberikan. Pada baris index = self.hash_function(key), program menghitung terlebih dahulu indeks penyimpanan menggunakan fungsi hash. Kemudian pada baris current = self.table[index], program mengambil node pertama yang berada pada bucket sesuai indeks tersebut. Langkah ini dilakukan agar proses pencarian langsung menuju lokasi data yang kemungkinan besar menyimpan key yang dicari.



















ada bagian while current is not None, program akan menelusuri setiap node yang ada pada linked list di bucket tersebut. Baris if current.key == key: digunakan untuk mengecek apakah key pada node saat ini sama dengan key yang dicari. Jika ditemukan, maka return current akan mengembalikan node tersebut sehingga data dapat diakses. Namun jika belum ditemukan, program akan berpindah ke node berikutnya melalui current = current.next. Jika seluruh node sudah diperiksa dan key tetap tidak ditemukan, maka program akan menjalankan return None yang menandakan bahwa data yang dicari tidak tersedia di dalam HashMap.

Pada codingan baris def remove_key(self, key):, kode ini berfungsi untuk menghapus data berdasarkan key yang diberikan. Pada baris index = self.hash_function(key), program menghitung terlebih dahulu indeks tempat data kemungkinan berada menggunakan fungsi hash. Kemudian pada baris current = self.table[index], program mengambil node pertama pada bucket tersebut, sedangkan prev = None digunakan untuk menyimpan node sebelumnya selama proses penelusuran linked list berlangsung.



















Pada bagian while current is not None, program akan menelusuri setiap node yang terdapat pada linked list untuk mencari key yang sesuai. Baris if current.key == key: digunakan untuk memeriksa apakah key pada node saat ini sama dengan key yang ingin dihapus. Jika data ditemukan dan node tersebut berada di posisi pertama linked list (prev is None), maka pointer bucket akan langsung diarahkan ke node berikutnya melalui self.table[index] = current.next. Namun jika node yang ditemukan berada di tengah atau akhir linked list, maka node sebelumnya akan langsung dihubungkan ke node setelahnya menggunakan prev.next = current.next.














Setelah data berhasil dihapus, program akan menjalankan return True yang menandakan bahwa proses penghapusan berhasil dilakukan. Jika key yang dicari belum ditemukan, program akan terus berpindah ke node berikutnya menggunakan current = current.next sambil memperbarui nilai prev = current sebagai penunjuk node sebelumnya. Apabila seluruh node sudah diperiksa tetapi key tidak ditemukan, maka program akan menjalankan return False yang menunjukkan bahwa data yang ingin dihapus tidak tersedia di dalam HashMap.

Pada codingan baris def display(self):, kode ini berfungsi untuk menampilkan seluruh data yang tersimpan di dalam HashMap. Pada baris print("\nIsi Data Buku (Separate Chaining):"), program akan menampilkan judul atau keterangan sebelum data ditampilkan. Kemudian pada bagian for i in range(self.SIZE):, program melakukan perulangan untuk memeriksa setiap bucket yang ada pada hash table, mulai dari indeks 0 sampai indeks terakhir. Baris print(f"{i}: ", end="") digunakan untuk menampilkan nomor indeks bucket, sedangkan current = self.table[i] digunakan untuk mengambil node pertama yang berada pada bucket tersebut.


















Pada bagian while current is not None, program akan menelusuri seluruh node yang terdapat pada linked list di bucket tersebut. Baris print(f"({current.key}, {current.value}) -> ", end="") digunakan untuk menampilkan data berupa kode buku dan judul buku yang tersimpan pada setiap node. Setelah data ditampilkan, program berpindah ke node berikutnya menggunakan current = current.next. Jika sudah tidak ada node lagi yang dapat ditelusuri, maka perulangan berhenti dan program menampilkan NULL melalui print("NULL"). Nilai NULL menunjukkan bahwa rantai linked list telah berakhir atau bucket tersebut tidak memiliki data yang tersimpan.

Hal ini menunjukkan bahwa proses pencarian dan penghapusan data berhasil dilakukan dengan baik tanpa memengaruhi data yang lain.
