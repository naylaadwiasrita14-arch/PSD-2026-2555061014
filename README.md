MENCARI NILAI UJIAN MAHASISWA

Program ini dibuat untuk mencari data nilai ujian mahasiswa berdasarkan nilai yang diinput oleh pengguna. Pengguna dapat memasukkan beberapa 
nilai mahasiswa, lalu program akan melakukan proses pencarian untuk mengetahui apakah nilai yang dicari tersedia di dalam data atau tidak. 
Jika nilai ditemukan, maka program akan menampilkan posisi atau letak nilai tersebut di dalam daftar. Untuk allgoritma yang diterapkan pada
program ini adalah algoritma Sequential Searching (pencarian data), yang digunakan untuk mencari suatu nilai dalam kumpulan data. Struktur 
data yang digunakan berupa array atau list yang gunanya untuk menyimpan nilai mahasiswa. Dengan adanya program ini, proses pencarian data 
akan menjadi lebih cepat dan mudah dilakukan dibandingkan mencari secara manual.

Potongan kode tersebut merupakan fungsi untuk melakukan pencarian data dengan metode  Sequential Search atau pencarian berurutan. Pada baris 
def sequential_search(data, n, target): , program akan mendefinisikan sebuah fungsi yang bernama sequential_search yang memiliki tiga 
parameter, yaitu data sebagai list yang berisi kumpulan nilai mahasiswa, n sebagai jumlah data dalam list, dan target sebagai nilai yang
ingin dicari. Selanjutnya, pada baris i = 0, program akan membuat variabel i dengan nilai awal 0 yang digunakan sebagai indeks atau penunjuk 
posisi data saat proses pencarian dimulai dari elemen pertama. Kemudian, pada baris counter = 0, dibuatnya variabel counter untuk menghitung 
berapa kali nilai target yang ditemukan di dalam list. 




---------------------------------------

Pada bagian while i < n:, program akan menjalankan perulangan selama nilai i masih lebih kecil dari jumlah ang artinya, program akan memeriksa data satu per satu mulai dari awal hingga akhir. Setelah itu, pada baris if data[i] == target:, program melakukan pengecekan apakah data pada posisi ke-i sama dengan nilai yang dicari. Jika kondisi tersebut benar, maka baris counter += 1 akan dijalankan untuk menambahkan nilai counter sebanyak satu. Ini berarti program menemukan data yang sesuai dengan target. Selanjutnya, pada baris i += 1, nilai indeks i ditambah satu agar program berpindah ke data berikutnya dan melanjutkan proses pencarian sampai seluruh data selesai diperiksa. Terakhir, pada baris return counter, program ini mengembalikan nilai counter sebagai hasil akhir, yaitu jumlah kemunculan nilai target di dalam list. Jadi, fungsi ini digunakan untuk mencari sekaligus menghitung berapa kali suatu nilai muncul pada kumpulan data mahasiswa.

Pada baris ke 19 ini fungsinya untuk meminta nilai yang ingin dicari sambil memastikan bahwa input yang diberikan oleh pengguna adalah valid. Di baris while True:, program akan menciptakan looping yang tidak terbatas yang akan terus berjalan hingga pengguna memberikan data yang benar. Selanjutnya, pada bagian try:, program berusaha untuk menjalankan kode yang terdapat di dalamnya untuk menghindari kesalahan saat input diterima. Pada baris target = int(input("Masukkan nilai yang ingin dicari: ")), program akan meminta pengguna untuk memasukkan nilai yang ingin dicari, dan kemudian mengubah input tersebut menjadi tipe data integer dengan menggunakan int(). Jika input berhasil dimasukkan dengan benar, maka perintah break akan menjalankan dan mengakhiri perulangan while True serta akan lanjut ke proses berikutnya. Namun, jika pengguna memberikan data yang bukan angka, program akan mengalami ValueError dan langsung beralih ke bagian except ValueError:. Di bagian ini, program menampilkan pesan "Input tidak valid, silakan masukkan angka! " agar pengguna menyadari bahwa input yang diterima harus berbentuk angka, Lalu program akan meminta input kembali karena perulangan tetap berlangsung. Setelah mendapatkan input yang valid, di baris counter = sequential_search(data, n, target), program akan memanggil fungsi sequential_search untuk mencari nilai di dalam daftar data, dengan jumlah total elemen n dan nilai yang sedang dicari target. Hasil dari pencarian ini selanjutnya disimpan dalam variabel counter.

Untuk Kode yang terakir, ini berfungsi untuk menunjukkan hasil dari pencarian nilai. Di baris if counter > 0:, program memeriksa apakah counter lebih besar dari 0, yang menunjukkan bahwa nilai yang dicari telah berhasil ditemukan dalam data. Jika kondisi ini terpenuhi, program akan mengeksekusi print(f"Nilai {target} ditemukan sebanyak {counter} kali. ") untuk menginformasikan bahwa nilai tersebut telah terdeteksi beserta frekuensi kemunculannya. Namun, bila nilai counter bernilai 0, maka else: akan dieksekusi dan program akan menyajikan pesan Nilai {target} tidak ditemukan, menandakan bahwa nilai yang dicari tidak terdapat dalam data. Selanjutnya, pada bagian if __name__ == "__main__":, program memeriksa apakah file dieksekusi secara langsung. Apabila iya, fungsi main() akan dipanggil untuk menjalankan keseluruhan program.
