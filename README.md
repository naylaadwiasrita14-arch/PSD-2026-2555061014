POGRAM PENGELOLAAN MENU DESSERT

Program pengelolaan menu dessert ini menggunakan konsep link 1 dimensi atau bisa disebut dengan array.  Program ini dibuatuntuk mengatur daftar makanan penutup dengan cara yang efisien. Yang dimana pengguna dapat menambahkan, menghapus, melihat, dan mengedit nama makanan penutup melalui menu yang ditampilkan di layar. Dengan  ini, program pengelolaan menu dessert berfungsi sebagai catatan makanan penutup yang dapat dimodifikasi kapan saja sesuai kebutuhan maupun pengguna.
Dalam program ini menggunakan list (1 dimensi) yang dimana untuk menyimpan informasi makanan penutup. Operasionalnya menggunakan perulangan (looping) agar program tetap aktif, serta percabangan (if-else) untuk menentukan tindakan berdasarkan pilihan pengguna. Dalam program ini juga menerapkan prinsip CRUD (create, read, update, delete) sehingga pengelolaan data menjadi lebih mudah.

Bagian kode ini, Fungsinya untuk buat mengatur cara menghapus dan melihat daftar makanan yang sudah kita simpan tadi. Kalau kita pilih menu nomor dua, program bakal minta kita untuk mengetik nama makanan yang mau dihapus, terus otomatis tulisannya akan terubah menjadi huruf kapital di bagian depanya dan nggak ada spasi berlebih di ujungnya. Setelah itu, program bakal ngecek dulu, kalau nama makanan itu beneran ada di dalam daftar, maka makanan tersebut langsung dihapus pakai perintah remove dan muncul pesan sukses. tapi kalau namanya nggak ketemu, program bakal kasih tahu kalau makanan itu nggak ada di daftar. Sementara itu, kalau kita pilih menu nomor tiga, program bakal ngecek apakah daftarnya masih kosong atau sudah ada isinya. Kalau ternyata masih kosong melompong, bakal muncul tulisan kalau belum ada makanan yang ditambahin, tapi kalau sudah ada isinya, program bakal nampilin semua nama makanan tadi satu per satu secara berurutan pakai nomor daftar biar tampilannya rapi dan gampang dibaca.
